# 04. Дорожная карта и список эпиков

Каждый этап выпускает работающий и проверенный срез. Файлы эпиков (`docs/epics/E*.md`) пишутся в Частях 2–4 и содержат: цель, сущности и поля, сценарии, состояния и переходы, API, права, события, ошибки, уведомления, i18n-ключи, критерии приёмки и тесты.

## M0. Фундамент

| Эпик | Содержание |
|---|---|
| E00.01 | Монорепо Nx, генераторы, теги и границы модулей |
| E00.02 | `tooling/lint`: TOML, генерация конфигов, раннер, хуки, формат коммитов |
| E00.03 | `core/config`: TOML + .env, валидация Zod |
| E00.04 | `core/bootstrap`: бутстрап сервера, `tooling/bootstrap-dev` (Docker Compose, индексы, миграции, минимальный контент) |
| E00.05 | `core/ts-utils`, `core/js-utils` |
| E00.06 | `design/tokens` (Style Dictionary), выходы для Tailwind, Material, NativeScript |
| E00.07 | `contracts`: Zod-схемы, базовые сущности, генерация OpenAPI и клиента |
| E00.08 | i18n: инфраструктура (ключи, ICU, плюрализация, fallback, CI-проверка пропусков), редактирование переводов в админке |
| E00.09 | Аутентификация, RBAC-матрица, аудит-лог |
