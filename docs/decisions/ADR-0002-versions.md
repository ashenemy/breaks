# ADR-0002. Фиксация версий инструментов и платформ

Статус: `accepted` (принято агентом по протоколу в задаче E00.01.01; пересматривается человеком).
Дата: 2026-10-04.

## Контекст

`docs/01-architecture.md` требует «последние стабильные версии на момент старта», зафиксированные в lockfile и ADR, и запрещает автообновление без отдельной задачи. На старте проверены актуальные версии в реестре npm и совместимость между ними. Ключевое ограничение: `@angular/compiler-cli@22.2` требует `typescript >=6.0 <6.1`, поэтому TypeScript 7.x (нативный компилятор) не используется.

## Решение

### Зафиксировано в E00.01.01

| Инструмент | Версия | Где зафиксировано |
|---|---|---|
| Node.js | 24.21.0 (LTS «Krypton») | `.nvmrc`, `engines.node` (`>=24.21.0 <25`) |
| pnpm | 12.9.1 | `packageManager`, `engines.pnpm`, corepack |
| Nx (`nx`, `@nx/*`) | 23.2.1 | `package.json`, `pnpm-lock.yaml` |
| TypeScript | 6.0.3 | `package.json` |
| tslib | 2.8.1 | `package.json` |

### Зафиксировано в E00.01.02

| Инструмент | Версия | Примечание |
|---|---|---|
| ESLint | 10.12.0 | Flat config; `@nx/eslint` и `@nx/eslint-plugin` 23.2.1 |
| `@eslint/js` | 10.0.1 | ESLint 10 не тянет его как зависимость, а `@nx/eslint-plugin` требует неявно, поэтому пакет закреплён в корне |
| typescript-eslint | 8.71.0 | Поддерживает TypeScript `<6.1` и ESLint 10 |
| Vitest | 5.0.3 | С `@vitest/coverage-v8` 5.0.3 и `vite` 8.3.2 (peer) |
| `@types/node` | 24.19.1 | Линия Node 24 |

### Фиксируются при первом подключении (в соответствующих эпиках)

| Платформа | Целевая линия на 2026-10-04 | Эпик |
|---|---|---|
| Angular | 22.2.x | E00.11, E01.01 |
| NestJS | 12.1.x | E00.04 |
| Tailwind CSS | 4.3.x | E00.06, E00.11 |
| NativeScript (`@nativescript/nx`) | 22.0.x | E00.12 |
| Biome | 2.5.x | E00.02 |

Точная версия записывается в этот файл в той задаче, где пакет впервые попадает в lockfile.

### Правила

1. `pnpm-lock.yaml` обязателен и коммитится; установка в CI только `--frozen-lockfile`.
2. Все зависимости пинятся точно (`.npmrc`: `save-exact=true`); диапазоны `^`/`~` запрещены.
3. `engine-strict=true`: установка с неподходящими Node или pnpm завершается ошибкой.
4. Скрипты сборки зависимостей запрещены, кроме allow-list `allowBuilds` в `pnpm-workspace.yaml` (сейчас только `nx`).
5. Обновление версий выполняется отдельной задачей через `nx migrate` (для Nx и плагинов) или явным изменением `package.json`; одновременно обновляется таблица выше.
6. Npm-scope рабочего пространства: `@market` (корневой пакет `@market/source`).

## Альтернативы

- TypeScript 7.x (latest): отклонён из-за несовместимости с Angular 22.
- Диапазоны версий (`^`): отклонены, воспроизводимость сборки важнее автоматических патчей.
- npm или yarn: отклонены, pnpm даёт строгую изоляцию зависимостей и блокировку скриптов сборки по умолчанию.

## Последствия

- Любое обновление осознанное и попадает в историю коммитов и в этот ADR.
- Новые пакеты устанавливаются с точной версией без дополнительных флагов.
- Разработчику нужны Node 24 и pnpm 12 (corepack включает нужную версию автоматически по `packageManager`).
