# E00.05. Утилиты: `core/ts-utils`, `core/js-utils`, `core/money`

Этап: M0. Зависимости: E00.01.

## Цель
Единое место для типов и функций, используемых более одного раза. Эти пакеты не зависят ни от чего, кроме стандартной библиотеки.

## `core/ts-utils` (только типы)
`Any` (единственное место разрешённого `any`, с пояснением), `Nullable<T>`, `Optional<T>`, `Awaitable<T>`, `Constructor<T>`, `ValueOf<T>`, `KeysOfType<T, V>`, `DeepPartial<T>`, `DeepReadonly<T>`, `Mutable<T>`, `RequireAtLeastOne<T>`, `NonEmptyArray<T>`, `Brand<T, B>`, `Prettify<T>`, `UnionToIntersection<U>`, `Result<T, E>`, `Primitive`, `JsonValue`.

## `core/js-utils` (функции)
- Проверки типов: `isString`, `isNumber`, `isBoolean`, `isBigInt`, `isSymbol`, `isFunction`, `isArray`, `isDate`, `isObject`, `isPlainObject`, `isNil`, `isNonEmptyString`, `isNonEmptyArray`, `isUuid`, `isObjectId`.
- Утверждения: `invariant`, `assertNever`, `assertDefined`.
- Коллекции: `pick`, `omit`, `groupBy`, `chunk`, `uniqBy`, `sortBy`, `partition`, `zip`, `range`.
- Объекты: `deepClone`, `deepEqual`, `deepMerge`, `getByPath`, `setByPath`.
- Асинхронность: `sleep`, `retry` (экспоненциальная пауза, джиттер, отмена), `debounce`, `throttle`, `withTimeout`, `pLimit`.
- Строки: `slugify` (с транслитерацией армянского и русского в латиницу), `truncate`, `escapeRegExp`, `maskPhone`, `maskEmail`.
- Каждая функция: JSDoc, юнит-тесты на граничные случаи.

## `core/money`
- Тип `Money = { amount: bigint | integer минимальных единиц; currency: CurrencyCode }`; `CurrencyCode`: AMD, RUB, EUR, USD (расширяемый реестр с количеством знаков).
- Операции: сложение, вычитание (только одной валюты), умножение на коэффициент с явным режимом округления (по умолчанию half-up, режим из конфига), сравнение, `allocate(money, ratios)` (деление без потери минимальной единицы), конвертация по курсу с фиксацией курса.
- Форматирование по локали (hy, ru, en) через `Intl`.
- Запрещены операции с числами с плавающей точкой над суммами. Тесты на свойства: сумма частей равна целому после `allocate`.
