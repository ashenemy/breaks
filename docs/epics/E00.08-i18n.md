# E00.08. Локализация (i18n): инфраструктура

Этап: M0. Зависимости: E00.01, E00.07.
Редакторский интерфейс переводов в админке делается в E01.05; здесь только ядро.

## Цель
Любая строка продукта переводится на hy, ru, en. Переводы можно менять без релиза. Пропущенные ключи ловятся до продакшна.

## Требования
1. Ключи: `<domain>.<screen|component>.<element>[.<variant>]`, нижний регистр, точки. Пример: `catalog.productForm.title.label`.
2. Формат сообщений: ICU MessageFormat (плюрализация, выбор, подстановки). Правила плюрализации по CLDR для hy, ru, en.
3. Веб и мобайл (Angular): рантайм-библиотека переводов (по умолчанию Transloco с плагином ICU; выбор фиксируется в ADR) с переключением языка без перезагрузки, ленивой загрузкой по неймспейсам и кэшированием. Тот же сервис используется в NativeScript.
4. Сервер: `I18nService` (ICU через `intl-messageformat`) для писем, SMS, push, PDF, ошибок API (`messageKey` в `ApiError` разворачивается на языке запроса по `Accept-Language` или профилю).
5. Хранение: коллекция переводов в MongoDB (`namespace`, `key`, `locale`, `value`, `version`, `status` draft или published, автор, время). Публикация создаёт неизменяемую версию, откат возможен.
6. Раздача: `GET /i18n/:locale/:namespace` с ETag и кэшем на CDN; клиент подгружает свежую версию без релиза приложения. Мобайл хранит локальную копию и работает офлайн.
7. Сборка: извлечение ключей из шаблонов и кода в `i18n/keys.json`. CI сверяет ключи с хранилищем и базовыми файлами в репозитории (начальные переводы лежат в репозитории и загружаются при `bootstrap-dev` и деплое). Отсутствие ключа в любом из hy, ru, en ломает сборку. Неиспользуемые ключи дают предупреждение.
8. Fallback во время работы: запрошенный язык, затем ru, затем en; факт fallback логируется и попадает в метрику.
9. Правило линтера: запрет захардкоженного текста в шаблонах и `ui-native` (E00.02).
10. Псевдолокализация (`pseudo`) для Storybook: удлинённые и подчёркнутые строки для поиска обрезаний.
11. Форматирование чисел, дат, валют по локали через `Intl` и `core/money`.
12. Локализованный контент сущностей (`LocalizedText`) использует ту же цепочку fallback; для публичных страниц обязательны `hreflang` и слаги по локалям (общий механизм слагов описан в E01.05).

## Критерии приёмки
- Переключение языка меняет весь интерфейс без перезагрузки; офлайн-копия работает в мобайле.
- Плюрализация корректна для чисел 0, 1, 2, 5, 11, 21 в ru и 0, 1, 2 в hy и en.
- Удаление перевода одного ключа на одном языке валит CI.
