# E00.11. Базовый набор `ui-web`, Storybook, доступность

Этап: M0. Зависимости: E00.06, E00.08.
Набор расширяется по мере потребностей эпиков: новый компонент добавляется отдельной задачей в `ui-web` до использования.

## Цель
Все веб-приложения используют только компоненты `ui-web`. Прямое использование Angular Material и нативных элементов вне пакета запрещено линтером.

## Требования
1. Каждый компонент:
   - оборачивает компонент Material (или реализован самостоятельно), типизированный публичный API, никаких внутренних строк (подписи, aria-label, плейсхолдеры приходят через входы как i18n-ключи или готовые тексты);
   - состояния: default, hover, focus, active, disabled, loading, error, empty (где применимо);
   - адаптив и RTL-безопасные отступы (логические свойства);
   - Storybook-истории по всем состояниям и вариантам, тест доступности (axe), снимки.
2. Типы свойств компонентов выделены в `ui-contracts`, чтобы `ui-native` реализовал тот же API там, где компонент имеет смысл.
3. Стартовый набор (около 35 компонентов): Button, IconButton, Link, TextField, TextArea, NumberField, MoneyField, PhoneField, Select, MultiSelect, Autocomplete, Checkbox, RadioGroup, Switch, Slider, RangeSlider, DatePicker, Chip, Tabs, Card, Dialog, Drawer, Menu, Tooltip, Toast, Table (сортировка, выбор строк, закрепление колонок, пагинация, массовые действия), Pagination, Stepper, Badge, Avatar, Skeleton, Spinner, ProgressBar, Breadcrumbs, FormField (подпись, подсказка, ошибка), FileUpload, EmptyState, ErrorState, Shell (шапка, боковое меню, контент), Icon (реестр иконок), типографика (директивы).
4. Токены применяются только через переменные из `design/tokens`; прямые значения цветов и размеров запрещены правилом.
5. Формы: интеграция с реактивными формами Angular и схемами Zod из `contracts` (ошибки на языке интерфейса).
6. Документация Storybook на всех трёх языках через псевдолокализацию и переключатель.

## Критерии приёмки
- Ни один компонент не содержит захардкоженного текста; тесты axe не находят нарушений уровня AA.
- Каждый компонент имеет истории по всем состояниям и проходит снимочные тесты.
- Импорт `@angular/material` вне `ui-web` ломает линтинг.
