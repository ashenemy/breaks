# E00.12. Спайк NativeScript

Этап: M0. Зависимости: E00.01, E00.06, E00.07.
Цель спайка: проверить решение «NativeScript + Angular с общими сервисами и токенами» до того, как на нём строится приложение (M7). Результат: ADR с решением go или no-go и запасным вариантом.

## Что проверяется
Общая логика (сервисы, состояние, клиент контрактов, i18n) и токены дизайна работают без правок в вебе и в NativeScript; отдельные view реализуются в `ui-native` с тем же API компонентов, что и в `ui-web` там, где есть смысл.

## Матрица проверок
| № | Возможность | Критерий |
|---|---|---|
| 1 | Список товаров с изображениями и ленивой подгрузкой | Плавная прокрутка 60 кадров на среднем устройстве |
| 2 | Карта (выбор адреса доставки) | Есть поддерживаемый плагин, работает на обеих платформах |
| 3 | Воспроизведение видео | Поддержка потокового воспроизведения, полноэкранный режим |
| 4 | Отображение HTML и rich-text описания товара | Корректный вывод заголовков, списков, изображений |
| 5 | Графики и диаграммы | Есть рабочее решение или обоснованная замена |
| 6 | Push-уведомления | Получение, открытие нужного экрана по ссылке |
| 7 | Глубокие ссылки и универсальные ссылки | Открытие товара и проекта из ссылки |
| 8 | Безопасное хранилище токенов | Хранение в Keychain и Keystore |
| 9 | Камера и галерея (фото для жалобы и отзыва) | Загрузка в S3 по presigned URL |
| 10 | Общий сервис из `modules/*/web` работает в приложении без изменений | Импорт и тест |
| 11 | Токены дизайна применяются в приложении | Снимок экрана совпадает с эталоном |
| 12 | i18n: переключение языка, офлайн-копия переводов | Работает без сети |
| 13 | Сборка и запуск на Android и iOS | iOS собирается на macOS-раннере |
| 14 | Размер приложения и время старта | Зафиксированы значения |

## Результат
ADR-0012: решение go или no-go. Если no-go, запасной вариант: Angular + Capacitor с общим UI-слоем (оценка влияния на `ui-native` и план M7 записывается в ADR). Задачи M7 корректируются в плане.
