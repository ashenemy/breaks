# E00.13. CI/CD и инфраструктура как код (staging)

Этап: M0. Зависимости: E00.01, E00.02, E00.04.
Production-окружение делается в E08.05. Задачи, требующие аккаунтов и ключей, помечаются как `blocked` до предоставления человеком.

## Цель
Любой коммит в PR проверяется автоматически; staging разворачивается воспроизводимо из кода.

## Требования: CI (GitHub Actions)
1. Workflow `ci`: установка зависимостей (кэш pnpm и Nx), линтинг, типизация, тесты `affected`, сборка, проверка i18n, проверка границ модулей, проверка формата и состава коммитов, проверка OpenAPI на breaking changes, аудит зависимостей, SBOM.
2. Workflow `e2e`: интеграционные и Playwright-тесты на Docker Compose с Testcontainers, запускается для затронутых приложений, артефакты (видео, трассировки) сохраняются.
3. Workflow `mobile`: сборки NativeScript для Android (Linux-раннер) и iOS (macOS-раннер), по расписанию и по тегам.
4. Workflow `deploy-staging`: сборка Docker-образов приложений, публикация в ECR, миграции, обновление сервисов ECS, дымовые тесты, откат при провале.
5. Доступ GitHub к AWS через OIDC (без долгоживущих ключей). Окружения GitHub с защитой и ручным подтверждением для prod.
6. Минимальные права токенов workflow; сторонние actions закреплены по SHA.

## Требования: IaC (Terraform или CDK, выбор в ADR-0004)
Модули: сеть (VPC, подсети, NAT, группы безопасности), ECS-кластер и сервисы (`api`, `worker`, `web-buyer`), балансировщик и сертификаты, RDS PostgreSQL, ElastiCache Redis, Amazon OpenSearch Service, S3 и CloudFront, SES, Secrets Manager, WAF, CloudWatch (логи, метрики, алерты), подключение к MongoDB Atlas (приватное соединение) и ClickHouse Cloud. Окружения разделены, состояние IaC хранится удалённо с блокировкой. Все ресурсы с тегами окружения и владельца. Базовые лимиты затрат и бюджетные алерты.

## Критерии приёмки
- PR с нарушением любого правила (стиль, коммит, граница модулей, пропуск перевода, breaking OpenAPI) не проходит CI.
- Staging разворачивается из чистого состояния одной командой; откат работает.
- В репозитории нет долгоживущих ключей AWS.
