# E01.02. Категории, подкатегории и библиотека свойств

Этап: M1. Зависимости: E01.01, E00.07, E00.05.

## 1. Цель
Админ управляет деревом категорий и библиотекой свойств; для каждой категории задан набор свойств (обязательных и необязательных) разных типов; на этой основе строятся карточки, фильтры, импорт и калькуляторы.

## 2. Сущности
- **Category**: `id`, `parentId`, `path` (материализованный путь), `name` (локализуемое), `slug` по локалям, `icon`, `order`, `status` (`active`, `hidden`, `archived`), `defaultUnit`, `seo`.
- **PropertyDefinition**: `key` (латиница, уникален), `label`, `help`, `type`, `unit`, `options` (локализуемые, с порядком и кодами), `validation` (min, max, шаг, regex, длина), `flags` (`filterable`, `searchable`, `showInCard`, `comparable`, `variantAxis`).
- **PropertyPreset**: именованная группа определений для повторного использования.
- **CategoryProperty**: связь категория → свойство: `required`, `order`, `group`, `overrides`.
- Типы свойств: `text`, `richtext`, `number`, `range`, `select`, `multiselect`, `boolean`, `switch`, `slider`, `color`, `dimension` (значение и единица).

## 3. Требования
- Подкатегория наследует свойства родителя, может переопределять `required`, порядок, группу; удалить унаследованное нельзя, можно скрыть.
- Изменение определения свойства версионируется; существующие значения в товарах не ломаются: несовместимое изменение (смена типа, удаление опции) требует миграции с отчётом о затронутых товарах.
- Удаление категории с товарами запрещено, допускается архивирование с переносом товаров.
- Слаги уникальны в пределах родителя и локали; транслитерация из названия по умолчанию.
- Админ-интерфейс: дерево с перетаскиванием, редактор категории, библиотека свойств и пресетов, предпросмотр формы карточки товара для категории.
- Публичный API: дерево категорий (кэшируется), свойства категории (с учётом наследования), фасеты.

## 5. Права, аудит, события
Раздел `catalog.categories`, `catalog.properties` (view, edit, delete). Аудит всех изменений. События `category.changed`, `property.changed` (для переиндексации поиска).

## 7. Ключи i18n
`admin.catalog.categories.*`, `admin.catalog.properties.*`, `property.type.*`.

## 8. Угрозы и меры
Rich-text значения свойств санитизируются. Регулярные выражения валидации проверяются на катастрофический откат (ReDoS) при сохранении.

## 9. Критерии приёмки
- Все 11 типов свойств создаются, валидируются и отображаются в предпросмотре.
- Наследование и переопределения работают на дереве глубиной не менее 4 (тесты).
- Несовместимое изменение блокируется без миграции; миграция выдаёт отчёт.
- Категорию с товарами нельзя удалить, можно архивировать.

## 10. Вне объёма
