# E01.04. Медиа-конвейер: изображения и видео

Этап: M1. Зависимости: E00.04, E00.13 (локально MinIO), E00.11.07.

## 1. Цель
Безопасная загрузка, обработка и раздача изображений и коротких видео для товаров, витрин и контента.

## 2. Требования
- Загрузка: клиент запрашивает presigned URL (проверка прав, типа, размера, квоты), грузит в S3 напрямую, сообщает о завершении; сервер проверяет фактический тип по содержимому.
- Сущность **MediaAsset**: `ownerRef`, `kind` (`image`, `video`), `status` (`uploaded`, `scanning`, `processing`, `ready`, `failed`, `rejected`), `hash` (дедупликация), оригинал, производные, размеры, длительность, `alt` (локализуемый), `order`.
- Изображения: проверка антивирусом (ClamAV), удаление EXIF, производные размеров и форматов (webp, avif, jpeg-запас), адаптивные `srcset`, цветовой профиль, ограничения размера и разрешения.
- Видео: ограничение длительности и размера (из настроек), транскодирование (mp4 H.264 и HLS), постер и превью, проверка кодека.
- Раздача через CDN с подписанными ссылками для приватных и кэшируемыми для публичных; отдельный домен для пользовательских файлов.
- Обработка в воркере через очередь с ретраями и dead-letter; прогресс доступен клиенту.
- Компонент загрузчика (в `ui-web`) использует этот API: очередь, прогресс, отмена, порядок, замена.
- Сборка мусора: неиспользуемые ассеты удаляются по расписанию после периода хранения.
- Интерфейс `MediaProcessor` для подключаемых обработчиков (в M2 к нему подключаются ИИ-функции и редакторы).

## 5. Права, аудит, события
Права: `media` (upload, view, delete) по области. События `media.ready`, `media.rejected`.

## 7. Ключи i18n
`media.error.*`, `media.status.*`, `media.uploader.*`.

## 8. Угрозы и меры
Подмена типа файла (проверка по сигнатуре), polyglot-файлы, SVG-скрипты (SVG не принимаются как пользовательские изображения либо санитизируются), zip-бомбы и «бомбы» декомпрессии изображений (лимиты пикселей), SSRF при загрузке по URL (запрещено в этом эпике), перебор URL (подписи и непредсказуемые ключи).

## 9. Критерии приёмки
- Файл с неверной сигнатурой, заражённый тестовым файлом EICAR, SVG со скриптом и изображение с экстремальным разрешением отклоняются.
- Из JPEG создаются все производные, EXIF удалён (проверка).
- Видео сверх лимитов отклоняется с понятной ошибкой на языке пользователя.
- Повторная загрузка того же файла не создаёт дубликат хранилища.
