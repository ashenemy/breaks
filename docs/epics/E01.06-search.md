# E01.06. Поиск: OpenSearch, армянский язык, транслитерация, синонимы

Этап: M1. Зависимости: E01.03, E01.02, E00.04.

## 1. Цель
Быстрый и качественный поиск товаров на hy, ru, en с упором на армянский: морфология, транслитерация между письменностями, синонимы из админки, опечатки, фасеты, подсказки.

## 2. Требования
- Индексы по языкам с общей схемой документа: название, описание, бренд, категория (путь), значения свойств, SKU вариантов, вендор, цена и наличие, рейтинг, популярность. Алиасы `products-<lang>` и перестроение без простоя (создать новый индекс, переключить алиас).
- Анализаторы: встроенные `armenian`, `russian`, `english` (стемминг, стоп-слова); общий фильтр транслитерации (армянский, русский, латиница) через собственную таблицу символов, настраиваемую в конфиге; нормализация регистра и диакритики; поиск по SKU и артикулам без морфологии.
- Синонимы: наборы в админке (группы слов на каждом языке и межъязыковые), применение через обновляемый поисковый анализатор без переиндексации.
- Допуск опечаток (fuzziness с порогами по длине слова), поиск по префиксу и автодополнение, «возможно, вы имели в виду».
- Фасеты строятся из определений свойств (`filterable`) и категории; диапазоны цен; наличие; рейтинг; вендор.
- Сортировка: релевантность, цена, новизна, популярность, рейтинг. Ранжирование: текстовая релевантность, затем бизнес-сигналы (наличие, рейтинг, популярность) с весами из настроек. Место для платных слотов заложено в запросе (заполняется в E05.04), результат помечает платные позиции отдельным полем.
- Индексация асинхронная из outbox (`product.changed`, `category.changed`, `property.changed`, `vendor.changed`), идемпотентная, с повтором. Полная переиндексация командой админа.
- Золотой набор запросов (≥150 для hy, ≥100 для ru, ≥50 для en, включая опечатки, транслитерацию, синонимы, артикулы) с ожидаемыми результатами; автоматический расчёт метрик (recall@10, MRR) в CI; падение ниже порога ломает сборку. Набор пополняется людьми.
- Векторное поле для эмбеддингов под ИИ-поиск закладывается в схему (заполняется в E05.01).
- Аналитика поиска: запросы без результатов, популярные запросы, клики (события в ClickHouse).

## 5. Права, аудит, события
Разделы `search.synonyms`, `search.reindex`. Аудит изменений синонимов и запусков переиндексации.

## 7. Ключи i18n
`search.suggest.*`, `search.noresults.*`, `admin.search.*`.

## 8. Угрозы и меры
Инъекции в запрос (только параметризованные запросы к OpenSearch, без передачи сырого DSL от клиента), DoS тяжёлыми запросами (лимиты глубины, размера, времени, rate limiting), утечка скрытых товаров (индексируются и отдаются только `published`).

## 9. Критерии приёмки
- Запрос на армянском с неточным окончанием, тот же запрос русскими и латинскими буквами и запрос с опечаткой находят ожидаемые товары на золотом наборе.
- Добавленный синоним начинает работать без переиндексации.
- Перестроение индекса не прерывает поиск.
- Скрытые, архивные и неопубликованные товары не попадают в выдачу.
- Метрики не ниже порогов, заданных в конфиге (стартово recall@10 ≥ 0,85).
