# E01.07. Импорт товаров из CSV и Excel

Этап: M1. Зависимости: E01.03, E01.04, E00.04.05.

## 1. Цель
Вендор и админ массово создают и обновляют товары из CSV и Excel. Архитектура позволяет быстро добавлять провайдеры (складские программы) без переписывания ядра.

## 2. Требования
- Интерфейс `ImportProvider`: `describe()`, `parse(stream)`, `normalize(row)`, `schema()`. На старте провайдеры `csv` и `xlsx`. Новый провайдер подключается регистрацией.
- Шаблоны файлов для категории: колонки строятся из свойств категории (обязательные помечены), языки названий и описаний, варианты, цены, остатки, единицы, медиа-ссылки. Шаблон скачивается из интерфейса.
- Процесс: загрузка файла → сопоставление колонок (автоподбор по заголовкам на hy, ru, en, ручная правка, сохранение профиля сопоставления) → предпросмотр первых строк → валидация всех строк → сухой прогон с отчётом → запуск.
- Режимы: создание новых; обновление по SKU; создание и обновление; только остатки и цены.
- Валидация построчно по правилам категории (E01.03). Ошибки и предупреждения с номером строки, колонкой, кодом и текстом на языке пользователя. Лимиты: размер файла, число строк, число колонок.
- Исполнение асинхронное в воркере, прогресс по строкам, возможность отмены, возобновление после сбоя с последней обработанной строки (идемпотентность по ключу строки).
- Отчёт с результатами (создано, обновлено, пропущено, ошибки) и скачиваемым файлом ошибок; откат всего пакета (возвращает прежние значения созданных и изменённых товаров).
- Изображения и видео по ссылкам: скачивание воркером только с разрешённых доменов, через защищённый клиент (запрет внутренних адресов, лимиты размера и времени); альтернатива: ZIP с файлами и колонкой имён.
- Импортированные товары попадают в `draft` или `pending_moderation` по настройке вендора.

## 5. Права, аудит, события
Раздел `import` (run, view, rollback) в области вендора и платформы. Аудит запусков и откатов. События `import.completed`, `import.failed`.

## 7. Ключи i18n
`import.step.*`, `import.error.*`, `import.report.*`.

## 8. Угрозы и меры
CSV и Excel инъекции формул (экранирование в отчётах и экспортах), SSRF по ссылкам, «бомбы» в XLSX и ZIP (лимиты распаковки), утечка чужих данных (изоляция по вендору), перегрузка (квоты на число одновременных импортов).

## 9. Критерии приёмки
- Файл на 5000 строк импортируется асинхронно; после принудительной остановки воркера продолжается без дублей.
- Ссылка на внутренний адрес и файл-бомба отклоняются.
- Откат пакета возвращает данные в исходное состояние.
- Ошибки показаны с номером строки и колонкой на языке пользователя.
