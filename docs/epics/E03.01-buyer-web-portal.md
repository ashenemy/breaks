# E03.01. Покупательский веб-портал (SSR)

Этап: M3. Зависимости: E01.06, E01.02, E01.05, E02.02, E00.08, E00.11.

## 1. Цель
Публичный сайт: каталог, поиск, карточка товара, витрины вендоров. SSR с гидрацией, высокая скорость, SEO, три языка.

## 2. Требования
- Приложение `apps/web-buyer` создаётся генератором. Маршрутизация с префиксом локали (`/hy`, `/ru`, `/en`), определение языка (URL, cookie, `Accept-Language`), сохранение выбора, `hreflang`.
- **SSR для всех** с гидрацией и кэшем на CDN; режим «SSR только для ботов» включается переключателем в конфиге (определение по User-Agent на уровне прокси или сервера, единый код рендера).
- **Шапка и подвал**: меню категорий (многоуровневое), поле поиска с подсказками, переключатели языка и валюты (подключаются в E03.06), корзина (подключается в E03.03), вход.
- **Главная**: блоки из CMS (баннеры, подборки), рендер с учётом расписания и сегментов.
- **Каталог**: страница категории, фасеты из свойств (`filterable`), диапазоны цен, наличие, рейтинг, вендор, сортировка, пагинация или подгрузка, состояние фильтров в URL, пустые состояния, хлебные крошки.
- **Карточка товара**: галерея (изображения и видео), выбор варианта (оси), единицы и упаковки с пересчётом, таблица ценовых ступеней, остаток и сроки готовности, блок вендора, характеристики по группам, слоты под отзывы (E04.04), похожие и сопутствующие (E05.05), доставку (оценка из E03.07), кнопки «в корзину» и «в проект» (E05.03).
- **Витрина вендора**: брендированная страница (CSS-переменные из токенов вендора, блоки, товары вендора с фильтрами).
- **Страница поиска**: результаты, автодополнение, «возможно, вы имели в виду», страница «ничего не найдено» с подсказками и популярными категориями.
- **Страницы CMS**: условия, конфиденциальность, возвраты и т.д.
- **SEO**: мета-теги по локалям, канонические ссылки, schema.org (Product, Offer, AggregateRating, BreadcrumbList, Organization), карта сайта по локалям с разбиением, `robots.txt`, Open Graph.
- **Аналитика и согласие**: баннер cookie, управление категориями согласия, SDK из E02.07.
- **Производительность**: бюджеты (LCP, CLS, INP) на мобильном профиле, ленивые изображения, адаптивные `srcset`, приоритет критичных ресурсов, Lighthouse CI в пайплайне.
- **Ошибки и состояния**: 404, 500, офлайн, медленная сеть, скелетоны.

## 5. Права, аудит, события
Публичные маршруты без авторизации; закрытые разделы (аккаунт) проверяются guard. События аналитики из E02.07.

## 7. Ключи i18n
`buyer.layout.*`, `buyer.catalog.*`, `buyer.product.*`, `buyer.vendor.*`, `buyer.search.*`, `buyer.seo.*`.

## 8. Угрозы и меры
XSS (санитизация контента, строгая CSP с nonce для SSR), открытые редиректы (белый список), раскрытие скрытых товаров (рендер только `published`), перегрузка SSR (кэш, лимиты, защита от cache poisoning через ключи кэша по локали и валюте), скрапинг (rate limiting, WAF).

## 9. Критерии приёмки
- Страницы отдаются с готовым HTML на всех трёх языках; `hreflang` и canonical корректны.
- Режим «SSR только для ботов» переключается конфигом без изменения кода.
- Валидатор schema.org принимает разметку товара; карты сайта содержат все опубликованные товары.
- LCP, CLS и INP в зелёной зоне на мобильном профиле на контрольных страницах.
- Скрытый или архивный товар отвечает 404.
