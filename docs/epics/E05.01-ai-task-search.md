# E05.01. ИИ-поиск по задаче

Этап: M5. Зависимости: E01.06, E02.05, E05.02 (частично), E03.01.07.

## 1. Цель
Пользователь описывает задачу своими словами («косметический ремонт детской, 12 м²»), система возвращает результаты, сгруппированные по этапам и группам товаров, которые участвуют в работе.

## 2. Требования
- **Понимание запроса**: TextProvider извлекает структуру по строгой схеме (тип работ, помещение, площадь и размеры, предпочтения и ограничения, бюджет, язык). Поддержка hy, ru, en. Если данных критически не хватает, система задаёт не более двух уточняющих вопросов в виде быстрых вариантов.
- **Шаблоны задач** (данные, редактируются в админке): сценарии работ (косметический ремонт, укладка плитки, утепление, кровля и т.д.) с этапами и группами товаров (например подготовка поверхностей: грунтовка, шпаклёвка, шлифовка; отделка стен: краска, инструмент для покраски). Планировщик использует шаблон как основу и адаптирует под запрос; если шаблона нет, предлагает план на основе категорий и знаний модели с обязательной проверкой по реальным категориям каталога.
- **Эмбеддинги**: `EmbeddingProvider` (мультиязычная модель) строит векторы товаров (название, описание, свойства, категория); индексация через outbox в векторное поле OpenSearch (E01.06.01), первичное заполнение задачей backfill, обновление при изменении товара.
- **Гибридный поиск по группе**: лексический и векторный поиск с объединением рангов (RRF), фильтры по свойствам из задачи (например «для детской» отображается на свойства безопасности и экологичности, если они есть), только `published` в наличии; платные слоты в этот режим не вмешиваются.
- **Объяснения**: для каждой группы и товара короткое пояснение, почему подходит, на языке пользователя (на основе свойств товара, без выдумывания характеристик).
- **Количества**: если известны размеры, используются калькуляторы (E05.02) для предложения количества.
- **Результат**: страница с группами по этапам, карточки товаров, фильтры внутри группы, кнопки «добавить группу в проект» и «в корзину» (E05.03), возможность уточнить задачу, оценка полезности (палец вверх и вниз).
- **Безопасность**: контент товаров и пользовательский ввод недоверенные; модель не вызывает инструменты; в ответ допускаются только идентификаторы товаров, полученные поиском (выдуманные отбрасываются); вывод проверяется по схеме и фильтрам; защита от prompt injection (тесты).
- **Надёжность и стоимость**: платформа оплачивает вызовы, лимиты на пользователя и сутки, кэш планов для похожих запросов, деградация без LLM (поиск по ключевым словам и шаблонам), метрики задержки и затрат.
- **Приватность**: запросы логируются без персональных данных (фильтрация номеров, адресов), срок хранения в настройках.
- **Качество**: золотой набор (не менее 50 типовых задач на трёх языках) с ожидаемыми группами и товарами, метрики покрытия групп и точности в CI.
- **Админ**: редактор шаблонов задач, сопоставление терминов задач с категориями и свойствами, просмотр оценок и запросов без хорошего результата.

## 5. Права, аудит, события
Раздел `ai_search` (view, edit_templates). События `aisearch.query`, `aisearch.feedback`. Аудит изменений шаблонов.

## 7. Ключи i18n
`buyer.aisearch.*`, `admin.aisearch.*`.

## 8. Угрозы и меры
Prompt injection через описание товара или запрос, галлюцинации товаров (только найденные идентификаторы), утечка системных инструкций, DoS по затратам (лимиты, кэш), смещение выдачи продавцами (защита текстов, платные места не участвуют).

## 9. Критерии приёмки
- Запрос «косметический ремонт детской» возвращает группы этапов с реальными товарами каталога на hy, ru, en.
- Выдуманные моделью идентификаторы и товары не попадают в результат (тест).
- При недоступности провайдера работает деградированный режим по шаблонам.
- Метрики золотого набора не ниже порогов из конфига.
