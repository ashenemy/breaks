# E07.01. Мобильное приложение покупателя: каркас и ui-native

Этап: M7. Зависимости: E00.12 (решение go по NativeScript), E00.11, E00.06.04, E00.08.

## 1. Цель
Каркас приложения для Android и iOS на NativeScript с Angular, набор нативных UI-компонентов с тем же API, что у `ui-web`, общая логика с вебом.

## 2. Требования
- **Приложение** `apps/mobile-buyer`, создаётся генератором и плагином NativeScript для Nx. Версии зафиксированы по результату спайка (ADR-0012). Если спайк завершился no-go, эпик заменяется запасным решением из ADR.
- **`ui-native`**: компоненты соответствуют типам из `ui-contracts` (E00.11.02): кнопки, поля ввода (текст, число, деньги, телефон), выбор и переключатели (select, multiselect, checkbox, radio, switch, slider), вкладки и навигация, карточка, бейдж, чип, скелетон, спиннер, прогресс, диалог и нижняя панель (bottom sheet), тост, рейтинг, цена, пустое состояние, состояние ошибки, степпер, карусель изображений, виртуальный список с подгрузкой и pull-to-refresh, таблица характеристик. Нативные элементы не используются вне пакета (линтер, как в веб).
- **Токены**: выход Style Dictionary для NativeScript (E00.06.04), светлая и тёмная темы, шрифты с армянскими глифами, масштабирование текста по системным настройкам.
- **Общая логика**: сервисы, хранилища состояния, типизированный API-клиент, DTO и контракты из общих пакетов; шаблоны отдельные.
- **Навигация**: нижние вкладки (Главная и каталог, Поиск, Проекты, Корзина, Аккаунт), стек экранов, глубокие ссылки (App Links на Android, Universal Links на iOS) на товар, вендора, категорию, проект по ссылке, заказ.
- **Хранение**: токены в защищённом хранилище (Keychain и Keystore), обычные данные в локальной базе или файловом кэше, очистка при выходе.
- **Сеть**: единый клиент с обновлением токена, повторами, таймаутами, обработкой офлайна, политиками кэша (каталог и категории кэшируются, корзина синхронизируется), сертификатное закрепление по настройке.
- **i18n**: сервис переводов из E00.08 с офлайн-кэшем пакетов на устройстве, переключение языка без перезапуска, форматирование чисел, валют и дат по локали.
- **Доступность**: TalkBack и VoiceOver, динамические размеры шрифта, контраст, размеры целей касания.
- **Аналитика и сбой-репорты**: SDK аналитики для NativeScript (E02.07.02), согласие пользователя при первом запуске, сбор ошибок и ANR.
- **Окружения и конфиг**: dev, staging, prod, публичный конфиг из `core/config`.
- **Галерея компонентов**: отдельное приложение `apps/mobile-gallery` с экранами всех компонентов и состояний (замена Storybook для нативных), снимки для ключевых экранов.
- **Тесты**: модульные (Vitest), компонентные, сценарные E2E на Maestro (ADR-0013), покрытие по правилам проекта.

## 5. Права, аудит, события
н/п (инфраструктура); события аналитики отправляются через SDK.

## 7. Ключи i18n
`mobile.common.*`, `mobile.nav.*`.

## 8. Угрозы и меры
Утечка токенов (защищённое хранилище, запрет логирования), перехват трафика (TLS, закрепление по настройке), обратная разработка (обфускация, проверка целостности по возможности), небезопасные глубокие ссылки (белый список путей, проверка параметров), резервные копии с секретами (исключение из бэкапа).

## 9. Критерии приёмки
- Приложение собирается под Android и iOS в CI, запускается, переключает язык и тему без перезапуска.
- Все компоненты `ui-native` покрывают те же контракты, что `ui-web`; прямые нативные элементы вне пакета блокируются линтером.
- Токены хранятся в защищённом хранилище и не попадают в логи.
- Глубокая ссылка на товар открывает нужный экран, неизвестные пути отклоняются.

## 10. Вне объёма
Экраны каталога, заказов и чата (E07.02, E07.03), публикация в магазинах (E07.04).
